Multi-Provider Settings

Configure how channels from multiple providers are handled.

When enabled, channels with the same name from different providers are merged into one. The best quality stream is shown, with automatic failover to other providers if it fails.
Automatically switch to another provider if the current stream fails. Requires "Merge Duplicate Channels" to be enabled.
Maximum number of providers to try before giving up (1-10). Default: 3.
Automatically select matching channels from another provider. Channels are matched by name (ignoring quality suffixes like HD/FHD).

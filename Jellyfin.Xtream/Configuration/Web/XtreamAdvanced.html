User-Agent Configuration

Automatically rotate through a pool of browser User-Agents to avoid WAF/DDoS protection blocking. Recommended when making many requests to providers with aggressive rate limiting.
If enabled, randomly selects User-Agents from the pool. Otherwise, rotates sequentially.

Rate Limiting

Limit the number of requests per second to avoid triggering WAF/DDoS protection. Recommended for providers with aggressive rate limiting.
Maximum API requests per second (1-100). Lower = safer but slower.
Recommended: 3-5 for aggressive WAFs, 10-20 for normal providers.
Maximum requests in initial burst before throttling (1-1000).
Allows quick bursts while maintaining average rate limit.

Connection Limits

Automatically manage concurrent streams to avoid exceeding your provider's connection limit. Useful for providers with limited connections (e.g., max 1-2 streams).
Maximum number of simultaneous streams allowed.
Set to 0 to automatically use the provider's limit.
When connection limit is reached, automatically stop the oldest stream to make room for the new one.
If disabled, new stream requests will fail with an error when limit is reached.

Buffer Diagnostics

Streams use automatic quality-based buffering that adjusts buffer size based on detected quality:
• SD/480p: 32MB buffer
• HD/720p: 64MB buffer
• Full HD/1080p: 64MB buffer
• UHD/4K: 128MB buffer

ℹ️ Requirements
This feature requires Discord webhook URL to be configured in the Discord Notifications section below.

Sends real-time diagnostics for all active buffer streams including:
  • Buffer size and utilization
  • Read/write statistics
  • Current lag/gap measurements
  • Buffer overflow events and data loss
  • MPEG-TS sync alignment status
  • Color-coded health status

External EPG

Use external XMLTV sources for EPG data and channel logos when your provider doesn't have them.
For Polish channels, epg.ovh provides free EPG and logos.

Enable fetching EPG data from external XMLTV sources as a fallback when your provider's EPG is unavailable.
URL to an external XMLTV file. Examples:
• Polish: https://epg.ovh/pl.xml
• UK: https://epg.ovh/uk.xml
• DE: https://epg.ovh/de.xml
Base URL for channel logos. The channel name is appended to form the full URL.
Leave empty to disable external logo fallback.
When a channel has no logo from the provider, attempt to fetch one from the external logo URL.
